# Pinned official input

`COMMIT` identifies the Version 2.3 reference revision used by the local
transcription. `PQCsignKAT_SNOVA_28_5_19_4.txt` is the first-record KAT input
used by the official-key correspondence harness. `SHA256SUMS` authenticates
these two pinned inputs.

The official C source and verifier are not vendored here. Consequently the
correspondence harness must not be described as a call to the unmodified
official verifier.
