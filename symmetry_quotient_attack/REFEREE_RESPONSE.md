# Response to the Mode-A referee report

The revision accepts the report's central criticism: the unit-leading
homotopy ledger is not a complete NIST classical-gate count. The abstract,
introduction, numerical tables, and conclusion use conditional break-even
language and display the exact allowable `kappa_hom` thresholds. The report's
verified structural results remain the basis of the paper.

## Mathematical and implementation-scope changes

1. The symmetry quotient, canonical output split, accepted-root theorem,
   complete-square reductions, and repair floors are retained.
2. The reserved line is a coordinate raw `A`-line; no arbitrary linear basis
   change is used before invoking independence of biased XOF symbols.
3. For all three `ell=2` rows, `rank(Q_R)=K` is an explicit fixed-key public
   preflight. No unproved random-key rank density is charged.
4. The unreproducible 16-orbit numerical branch and low-state XL numerical
   table are removed.
5. The package and checker descriptions distinguish exact recomputation from
   official-verifier testing, which remains future work.

## Corrections ported from the independent editor

The editor correctly identified that SNOVA's outer map is fixed and cannot be
assigned a random full-rank probability. The paper now conditions on exact
public checks `rank(Q_R)=K` and fixed-layout coefficient-map ranks, applies
random-XOF probability only to sampled native public-form coefficients, uses
projective quotient directions in the affine-rank union bound, and removes the
former structural-probability normalization from all `ell=4` ledgers.

The audit also confirms the editor's strengthened finite-cardinality
homotopy proof, exact target-sampling calculation, coordinate-aligned
freshness condition, corrected three-plus-one completion proof, table
terminology, bibliography placement, and publication metadata.

One editor correction had accidentally not been carried into the combined
manuscript: with zero offsets the attacker uses the full `A^v` vinegar space,
not `A^(v-1)`. The corrected dimension-only repair range is therefore
`101.5625%--144.00%`, with the exact nine-row table regenerated by the
checker.

## Correction to the later Just Guess section

The diagonal and Hermitian Frobenius channels are distinct linear images of
the same byte-biased native coefficients. They are not independent after
conditioning on the diagonal channel. The revised proof diagonalizes the
official `ell=2` matrix and exhaustively enumerates the exact conditional
channel distributions. It obtains

- maximum diagonal-block conditional atom `49/829`;
- maximum off-diagonal nonzero-functional conditional atom
  `169246/2971565 < 49/829`.

The cross-channel second moment now uses `rho_cond=49/829`. At candidate
fraction `c=1/4`, its success lower bound is `0.0961344407`, not `0.171052`.
The corrected expected-operation ledger is

    135.425325 + log2(kappa_JG),

with Level-I break-even condition

    log2(kappa_JG) < 7.574675.

The capped schedule becomes

    141.092306 + log2(kappa_JG_cap),

with break-even threshold `1.907694` bits. The target sampler also rejects
`t_D=0`, and `kappa_JG` now explicitly includes candidate abundance,
transformation/linearization retries, and any candidate-processing cost above
the declared reserve.

These changes weaken the numerical sensitivity slightly but remove an
incorrect independence premise. No unconditional Level-I complete-gate break
is claimed.
